帕秋莉手册（Patchouli）可视化编辑器 —— **单文件 HTML**，双击即用。

## 下载

`Patchouli-Helper-v0.1.3.html`，用 Edge / Chrome 打开即可。不需要安装、不需要 Node、不需要联网。

## 本次修复：多语言状态显示混乱

导入一本带 `en_us / zh_cn / zh_tw` 的模组后，切到简体中文仍看到英文，界面也**不给任何提示**——因为判断「这条有没有译文」用的是带回退的 `getText()`，永远能取到 en_us 的内容，于是永远判定为「有译文」。

修法：全面改用不带回退的 `isTranslatedFor()` 逐槽统计真实译文。

- **语言按钮按覆盖率上色**：绿点 = 100% 全译，黄点 = 部分翻译，空心虚线圈 = 一处都还没译；鼠标悬停显示 `已翻译 5/9 处（56%）`
- **顶部提示条**：当前语言不全时出现一条蓝条，说明「已翻译 N/M 处，标『未译』的条目显示的是 en_us 回退文本」；零译文时说明「改动会保存到 zh_tw，不会动 en_us」
- **切换语言时弹提示**：切到无译文的语言会提示「先显示 en_us 回退文本，输入后即保存为 zh_tw」
- **树里的徽标**：未翻译的条目/分类由原来的语言缩写改成明确的「未译」标签
- **字段级提示**：编辑未翻译条目时，名称下方显示「zh_cn 未翻译：导出时这里会用回退语言（en_us）的文本」（以前这条提示永不出现）
- **状态栏**：`zh_cn 56%`，一眼看出当前语言完成度

语义澄清：Patchouli 的回退语言固定是 `en_us`，与「基准语言」无关；覆盖率以 `en_us` 中确实写了内容的槽位为分母，本来就没写的字段不会被算成缺翻译。
