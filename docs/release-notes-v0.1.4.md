# Patchouli Helper v0.1.4

帕秋莉手册（Patchouli）可视化编辑器 —— **单文件 HTML**，双击即用。

## 下载

`Patchouli-Helper-v0.1.4.html`，用 Edge / Chrome 打开即可。不需要安装、不需要 Node、不需要联网。

## 本次修复：把「翻译完成度」的算法改对了

v0.1.3 引入的完成度是按**字段槽位**算的，会把下面这些情况算成「缺翻译」，于是中文写全了也显示 56%：

- 书 `name` / `landing_text` 存在 `book.json` 里，**一个文件、按语言无关**，永远不会「有中文版本」
- 页面 `title` 本来就可以留空（Patchouli 允许无标题页）
- Patchouli 的回退粒度是**整份文件**，缺一个字段不等于这条目没中文

现在改成**按会导出哪个文件**统计，和 `serializeContent` 的判定完全一致：

- 文件夹模式：`zh_cn/categories/*.json`、`zh_cn/entries/*.json` 有几个真的会生成 / 一共几个
- i18n lang key 模式：按 lang key 逐条统计

全译的书现在就是 **100%**，不再误报。

## 新增：未翻译清单（可直接点过去改）

提示条上的 **「查看明细」** 会列出到底哪几条没译：

```
zh_cn 未翻译清单（2）
条目「intro」  在 zh_cn 里没有内容    assets/<modid>/patchouli_books/<book>/zh_cn/entries/intro.json   警告
条目「second」 在 zh_cn 里没有内容    .../zh_cn/entries/second.json                                 警告
```

点一条直接跳过去编辑。数字和清单对得上，就不必再猜「到底哪儿没译」。

## 新增：编辑框不再把 en_us 冒充成译文

以前未翻译的字段会把 en_us 的文本直接填进输入框，看着像「已经译好了」。现在：

- 输入框里**只有本语言真正存的内容**（没有就是空的）
- 占位提示写明：`（zh_cn 未填写，游戏里显示 en_us：Presser）`
- 富文本下方同样提示 `zh_cn 未填写：游戏里这里显示 en_us 的「…」`
- 左侧树的「未译」标签也改为**整条判定**（条目正文译了、只有标题空着，不再挂「未译」）
- 预览区仍然按游戏真实效果渲染（回退 en_us），所以「所见即游戏所见」
